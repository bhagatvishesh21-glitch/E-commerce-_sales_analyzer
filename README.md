# E-Commerce Sales Analyzer

## 1. Project Description
The E-Commerce Sales Analyzer is a Python-based project that analyzes sales data from an online store. It helps users understand sales performance, category-wise revenue, and top-selling products.

## 2. Features
- **Summary:** Displays a summary of sales data.
- **Category-wise Revenue:** Shows revenue generated by each product category.
- **Top Products Bar Chart:** Displays the top products using a bar chart.
- **Interactive Menu:** Allows users to select different analysis options.
- **Exit Option:** Allows users to close the program.

## 3. Technologies Used
- Python
- Pandas
- Matplotlib
- CSV File

## 4. Requirements
Install Python on your computer.

Install the required libraries using:

```bash
pip install pandas matplotlib
```

## 5. Project Structure

```text
E-Commerce-Sales-Analyzer/
├── main.py
├── orders.csv
└── README.md
```

**Note:** The `main.py` file contains the Python program, and `orders.csv` contains the sales data.

## 6. How to Run the Project

1. Install Python.
2. Install Pandas and Matplotlib.
3. Place `main.py` and `orders.csv` in the same folder.
4. Open a terminal in the project folder.
5. Run the following command:

```bash
python main.py
```

## 7. Menu Options

When you run the program, the following menu appears:

```text
=== E-Commerce Sales Analyzer Menu ===
1. Summary
2. Category-wise revenue
3. Show Top Products Bar Chart
4. Exit
```

Enter your choice to perform the required analysis.

## 8. Expected Output
- A summary of the sales data.
- Revenue generated by each product category.
- A bar chart of the top products.
- An exit message when the program closes.

The exact output depends on the data in `orders.csv`.

## 9. Conclusion
The E-Commerce Sales Analyzer is a simple Python project that helps analyze e-commerce sales data. It uses data analysis and visualization to make sales information easier to understand.

**Important:** The program also needs the functions `load_and_clean_data()`, `display_summary()`, `display_category_revenue()`, and `show_top_products_chart()` to be defined in the Python code. The `orders.csv` file must contain the columns expected by those functions.
